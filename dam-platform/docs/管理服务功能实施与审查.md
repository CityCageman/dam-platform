# 管理服务功能实施与审查

## 1. 本轮范围

将三个骨架服务升级为数据库支撑的管理面：

```text
dam-integration   集成任务管理
dam-scheduler     调度任务管理
dam-data-service  数据 API 与订阅管理
```

不包含：

```text
真实数据同步执行引擎
真实 DAG 调度执行引擎
数据 API 网关运行时
```

## 2. 服务与表

### dam-integration

```text
schema: dam_integration
table: integration_job
```

API：

```text
GET    /api/integration/jobs
GET    /api/integration/jobs/{id}
POST   /api/integration/jobs
PUT    /api/integration/jobs/{id}
DELETE /api/integration/jobs/{id}
POST   /api/integration/jobs/{id}/status
POST   /api/integration/jobs/{id}/trigger
```

trigger 行为：

```text
只记录 last_run_at 和 last_error
不把任务置为 RUNNING
返回 taskCreated=false
```

原因：没有执行引擎时置为 RUNNING 会让任务永久停在运行中。

### dam-scheduler

```text
schema: dam_scheduler
tables:
  schedule_job
  schedule_run
```

API：

```text
GET    /api/scheduler/jobs
GET    /api/scheduler/jobs/{id}
POST   /api/scheduler/jobs
PUT    /api/scheduler/jobs/{id}
DELETE /api/scheduler/jobs/{id}
POST   /api/scheduler/jobs/{id}/status
POST   /api/scheduler/jobs/{id}/trigger
GET    /api/scheduler/jobs/{id}/runs
GET    /api/scheduler/dags
```

trigger 行为：

```text
插入 schedule_run，状态 PENDING
返回 runId
不伪造执行成功
```

### dam-data-service

```text
schema: dam_data_service
tables:
  data_api
  api_subscription
```

API：

```text
GET    /api/data-service/apis
GET    /api/data-service/apis/{id}
POST   /api/data-service/apis
PUT    /api/data-service/apis/{id}
DELETE /api/data-service/apis/{id}
POST   /api/data-service/apis/{id}/publish
POST   /api/data-service/apis/{id}/offline
GET    /api/data-service/apis/{id}/subscriptions
POST   /api/data-service/apis/{id}/subscriptions
POST   /api/data-service/subscriptions/{id}/status
GET    /api/data-service/subscriptions
```

publish 只改变管理状态，不创建真实 API 网关路由。

## 4. 审查结论

### 已修正

1. integration trigger 不再把任务置为 RUNNING；
2. 三个服务 POM/application.yml 已接入数据库；
3. 逻辑删除、编码唯一、状态校验已实现；
4. 全量 Maven reactor package 通过；
5. 未伪造同步/调度/API 发布成功。

### 需要生产部署前确认

1. 数据库账号对以下 schema 有权限：

```text
dam_integration
dam_scheduler
dam_data_service
```

2. 新服务需要数据库连接：

```text
SPRING_DATASOURCE_URL
SPRING_DATASOURCE_USERNAME
SPRING_DATASOURCE_PASSWORD
```

3. 新服务当前是管理面，不是执行引擎。
4. 真实数据库联调尚未执行；本轮验证到编译和启动骨架级别。
5. `dam-scheduler` 和 `dam-data-service` 的 trigger/publish 只产生管理状态，不产生真实运行结果。
