# 阶段 1：统一门户验收清单

## 1. 入口

- 登录后可以从左侧导航进入「统一门户」。
- 统一门户首页展示 8 个能力域卡片。
- 每个能力域进入后展示对应模块卡片。

## 2. 8 个能力域

```text
资产 asset
标准 standard
工程 engineering
治理 governance
分析 analytics
服务 service
AI ai
平台 platform
```

## 3. 23 个模块

```text
asset: DAM MDM
standard: STD MDL
engineering: INT DEV SCH STO
governance: DQ LIN SEC LIF
analytics: MET RPT
service: DS MKT
ai: KNO AI MGW
platform: TC OPS SYS OBS
```

## 4. 路由

```text
/portal
/domains/asset
/domains/standard
/domains/engineering
/domains/governance
/domains/analytics
/domains/service
/domains/ai
/domains/platform
```

旧路由保持可访问，不允许 404。

## 5. 后端 API

```text
GET /api/portal/status
GET /api/portal/domains
GET /api/portal/domains/{code}
GET /api/portal/home/summary
```

## 6. 验收

- 后端 dam-portal 编译通过。
- 前端 vue-tsc、vite build 通过。
- 网关增加 /api/portal/** 路由。
- 门户卡片可点击进入现有页面或标注“规划中”。
- 不删除现有菜单、不改变现有业务接口。
- 不进行数据库迁移。
- 不打包 tar。
