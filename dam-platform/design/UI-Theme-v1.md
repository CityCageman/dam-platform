# DAM UI 四色主题 v1

参考 Logo 的四色组合，主色采用深紫，青绿/金黄/草绿作为功能与状态点缀。

## 色板

| Token | 色值 | 用途 |
|---|---|---|
| `--med-primary` | `#72156A` | 品牌主色、主按钮、选中态、链接 |
| `--med-primary-dark` | `#560E50` | 深色侧栏、按下态 |
| `--med-primary-lighter` | `#F7EDF6` | 选中背景、浅色标签 |
| `--med-accent` | `#2FA6A1` | 青绿辅助色、AI 渐变、成功状态 |
| `--med-gold` | `#D99A1C` | 待处理、提醒、统计卡第 3 色 |
| `--med-green` | `#5BAE47` | 通过、完成、统计卡第 4 色 |
| `--med-bg` | `#F8F5F8` | 页面暖灰底色 |
| `--med-text` | `#2B2530` | 主文字 |
| `--med-text-secondary` | `#655D68` | 次级文字 |
| `--med-border` | `#EAE2EA` | 卡片/表格边框 |

## 组件规则

- **侧栏**：深紫渐变 `#4A0D45 → #23061F`，选中项紫色到青绿渐变，左侧金黄指示条。
- **顶栏**：白色、细边框、浅紫阴影；搜索框暖灰底。
- **页面标题**：左侧四色渐变竖条（紫 → 青绿 → 金黄）。
- **统计卡**：四张卡按紫、青绿、金黄、草绿循环，顶部 3px 色条 + 同色浅色圆斑。
- **面板**：16px 圆角，轻阴影；标题左侧紫到青绿渐变竖条。
- **主按钮**：深紫实底；AI 按钮紫到青绿渐变。
- **表格**：暖白表头、浅紫 hover、弱边框。
- **图表**：紫、青绿为主，金黄、草绿用于分类与状态。
