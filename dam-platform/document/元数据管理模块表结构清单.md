# 元数据管理模块表结构清单

> 范围：当前 `dam-catalog` 模块中，与技术元数据采集/数据源管理相关的全部表。
> 说明：`dam_asset` / `dam_field` 为采集结果的落地目标表（属于资产目录域，但被采集服务直接写入），一并列出以便理清关联。

---

## 一、数据源类型配置（dam_system）

### 1. dam_data_source_type — 数据源类型配置表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | ✅ | 自增 | 主键 |
| type_key | VARCHAR(50) | ✅ | - | 类型编码，如 MYSQL / POSTGRESQL / ORACLE（唯一） |
| type_name | VARCHAR(100) | ✅ | - | 显示名称，如 MySQL / PostgreSQL |
| driver_class | VARCHAR(200) | ✅ | - | JDBC 驱动类全限定名 |
| url_template | VARCHAR(500) | ✅ | - | JDBC URL 模板（%s=host, %d=port, %s=databaseName） |
| default_port | INT | ✅ | - | 默认端口 |
| catalog_mode | VARCHAR(20) | ❌ | database | catalog 策略：database / null / schema |
| pk_strategy | VARCHAR(30) | ❌ | information_schema | 主键策略：information_schema / pg_catalog / jdbc_get_primary_keys |
| system_schemas | VARCHAR(500) | ❌ | - | 系统 schema 过滤关键字（逗号分隔） |
| sort_order | INT | ❌ | 0 | 排序号 |
| status | INT | ❌ | 1 | 状态：0 禁用 / 1 启用 |
| remark | VARCHAR(500) | ❌ | - | 备注 |
| created_at | TIMESTAMP | ❌ | 当前时间 | 创建时间 |
| updated_at | TIMESTAMP | ❌ | 当前时间 | 更新时间 |

## 五、当前关联关系一览

```
dam_data_source_type (类型模板) ──type_key──> dam_data_source (实例)
                                                    │
                                  database_name 字符串弱关联（⚠️ 问题点）
                                                    ▼
                                              dam_asset (表资产)
                                                    │ asset_id
                                                    ▼
                                              dam_field (字段)
```

| 关联 | 类型 | 强度 | 问题 |
|------|------|------|------|
| data_source_type → data_source | type_key | 强（字段值） | 无外键约束，但语义明确 |
| data_source → asset | database_name | **弱（字符串匹配）** | 同名库错配 / 改名失效 |
| asset → field | asset_id | 强（外键） | 正常 |
| collection → asset | 无 | 无 | 无法追溯来源 |
