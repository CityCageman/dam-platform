## 本次评审重点

- 是否认可「中台负责数据生产、DAM 负责治理」；
- 是否认可数据源/扫描、模型/DDL、质量执行完全归中台；
- 是否认可质量执行归中台、规则定义归 DAM；
- 是否认可数据源注册中心归中台；
- 策略范围是否先做质量规则 + 安全策略；下发采用「中台拉取」还是「DAM 推送」；
- MVP 是否包含字段级元数据同步、资产注册、血缘、质量结果、策略下发；
- BIZ 作为业务域放在 DWS/ADS；DWD 是否建设。
