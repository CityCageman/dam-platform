# DAM 增量更新说明（2026-11-13）

本次为 2026-11-12 包之后的增量更新，主要包括 AI 服务拆分、数据库隔离、指标/知识边界和冗余清理。

## 1. 模型网关重命名

原 `dam-agent` 服务重命名为 `dam-model-gateway`：

```text
模块：dam-model-gateway
端口：8089
新接口前缀：/api/model-gateway
兼容旧接口：/api/agent
```

模型网关只负责：

- 模型调用；
- 流式 SSE；
- 一次性完成；
- 模型 Key；
- 超时与重试。

新增配置：

```text
DAM_MODEL_GATEWAY_CODE_BASE_URL
DAM_MODEL_GATEWAY_CODE_API_KEY
DAM_MODEL_GATEWAY_CODE_MODEL
DAM_MODEL_GATEWAY_URL
DAM_ROUTE_MODEL_GATEWAY
```

旧 `DAM_AGENT_*` 保留兼容，但新部署不再使用。

## 2. 新增 dam-ai-workbench

新增 AI 编排服务：

```text
模块：dam-ai-workbench
端口：8090
接口前缀：/api/ai-workbench
```

已迁移到工作台：

- AI 任务中心；
- AI 任务分页、详情、取消、审核；
- 报表生成任务；
- 报表草稿审核；
- 报表生成编排；
- 任务历史上下文；
- AI 限流。

前端已切换：

```text
/catalog/ai/tasks         → /ai-workbench/ai/tasks
/catalog/report/generate  → /ai-workbench/reports/generate
```

## 3. AI 任务表迁移到 dam_ai

新增：

```text
dam_ai.ai_task
dam_ai.ai_task_item
```

catalog 不再直接读写 AI 任务表：

- 删除了 catalog 的 AiTaskService、AiTaskRunner、AiTaskMapper；
- catalog 通过 workbench 内部任务接口写草稿；
- workbench 通过 catalog 内部工具接口访问元数据、报表和 SQL 执行。

新增工作台数据库配置：

```text
DAM_AI_DB_URL
DAM_AI_DB_USERNAME
DAM_AI_DB_PASSWORD
```

建议 `dam-ai-workbench` 使用独立数据库账号，只授权 `dam_ai` schema。

## 4. 指标库与知识库边界

知识条目新增指标关联：

```text
knowledge_entry.metric_id
```

规则：

- 类型为「指标解释」的知识条目必须关联指标库；
- 公式、来源表、SQL、取数规则以指标库为准；
- 知识库只维护解释、别名、使用说明、案例和变更背景；
- 知识库页面隐藏指标类型的「参考 SQL」和「取数规则」编辑区。

指标库新增：

```text
metric_definition.report_spec
```

指标编辑页面增加取数规则：

- 规则状态；
- 统计粒度；
- 去重键；
- 必用表；
- 业务条件；
- 主报表 SQL；
- 下钻 SQL。

AI 报表会优先使用指标库的口径和规则。

## 5. AI 报表能力

- AI 报表生成前检索 WeKnora/本地知识库；
- 知识库内容参与表结构检索和 Prompt；
- 支持按指标库规则校验必用表；
- 支持生成下钻 SQL；
- 报表中心、AI 对话支持点击人数等数值列下钻；
- 下钻失败时显示具体 SQL 和校验错误；
- 生成报表时 NEW 模式不再自动携带上一张报表 SQL，避免口径污染；
- 修复表注释显示旧值的问题；
- 修复解析状态旧错误残留问题。

## 6. 冗余清理

- 删除 catalog 已失效的 `AiAsyncConfig`；
- 合并重复的 `JsonbTypeHandler` 到 dam-common；
- 合并重复的 `AiRateLimiter` 到 dam-common；
- 抽取前端重复下钻参数逻辑到 `utils/reportDrill.ts`；
- 清理部署脚本和文档中的 `dam-agent` 旧命名；
- 清理未使用的模型网关 chat 环境变量。

## 8. 部署变化

新增服务：

```text
dam-model-gateway
dam-ai-workbench
```

systemd 增加：

```bash
systemctl enable --now dam@dam-model-gateway
systemctl enable --now dam@dam-ai-workbench
```

网关新增路由：

```text
/api/model-gateway/** → dam-model-gateway:8089
/api/agent/**         → dam-model-gateway:8089（兼容）
/api/ai-workbench/**  → dam-ai-workbench:8090
```

## 9. 兼容性说明

- 旧 `/api/agent` 接口暂时保留；
- 旧 `DAM_AGENT_*` 环境变量暂时兼容；
- 历史知识条目的指标关联会尽量从 `source_key=metric:<id>` 回填；
- 手工创建但没有关联指标的指标解释，需要在页面重新选择指标；
- 历史报表需要重新生成，才能使用新的指标规则和下钻能力。
