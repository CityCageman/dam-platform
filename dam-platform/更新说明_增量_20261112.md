# DAM 增量更新说明（2026-11-12）

本次为 2026-11-10 包之后的增量更新，主要围绕知识库体系与 WeKnora 同步。

## 1. 知识库分类升级为树形结构

- 知识分类支持父分类、子分类、分类路径和层级；
- 左侧按树形缩进展示；
- 新增分类时可选择父分类；
- 分类改名或移动时，自动更新所有子分类路径；
- 分类维护增加“分类说明”，用于说明该分类放什么内容，例如：
  - 业务术语：解释病人号、就诊号等业务对象；
  - 指标解释：说明指标口径和统计范围；
  - 标准与编码：诊断、手术、药品等标准；
  - 案例与变更：异常、口径修正、版本变更。

## 2. 知识条目结构化

知识条目从自由文本升级为结构化维护，新增：

- 知识类型：业务术语 / 指标解释 / 标准与编码 / 案例与变更；
- 业务解释；
- 使用说明；
- 别名/同义词；
- 字段映射；
- 关联指标；
- 来源系统；
- 负责人；
- 发布状态；
- 版本；
- 生效时间。

“病人号”这类内容可以完整维护为：

```text
分类：业务术语/患者与主索引
类型：业务术语
解释：病人号是患者唯一号，也叫主索引 ID……
别名：患者唯一号、主索引 ID、PAPMI_No
字段映射：PA_PatMas.PAPMI_No → 病人号
使用说明：患者、就诊、费用等数据关联时使用
关联指标：门诊量、住院人次
来源系统：HIS / 患者主索引
负责人：...
状态：已发布
```

## 3. AI 归类

知识编辑页面增加「AI 归类」：

- 读取当前分类树、分类说明、标题和解释；
- 推荐分类、知识类型、别名、字段映射、关联指标、使用说明；
- 返回推荐理由；
- 人工确认后保存，不直接静默改库。

## 4. WeKnora 知识库同步

- 采用“一个 WeKnora 知识库 + 分类路径标签”；
- DAM 分类树映射为 WeKnora 路径标签，例如：
  ```text
  业务术语/患者与主索引
  ```
- 标签按 DAM 分类树 DFS 顺序设置排序；
- 匹配优先使用 DAM 保存的 `external_tag_id`，不按叶子名称匹配；
- 标签被删除后按完整路径兜底查找；
- 修复 WeKnora 标签分页返回 `data.data` 导致标签被误判为空的问题；
- 修复同名标签冲突时无法复用的问题；
- 新增知识保存后自动同步 WeKnora；
- 提供「Agent 同步」统一执行：创建/修复知识库、绑定模型、同步分类标签、同步知识文档、刷新解析状态；
- 外部文档写入后同步回 DAM：
  - 摘要；
  - custom_metadata；
  - 标签；
  - 解析状态；
  - 错误信息。

## 5. 解析状态自动更新

- 新增后台轮询：对“解析中”的文档自动查询 WeKnora 状态；
- 前端在存在解析中条目时自动刷新列表；
- 解析成功后清除历史错误；
- 解析失败记录失败原因；
- 修复 MyBatis-Plus 不更新 null 字段导致旧错误残留的问题。

## 6. WeKnora 初始化与模型

- 支持默认模型绑定：
  - LLM：`qwen3-coder-30b-a3b`
  - Embedding：`bge-m3`
- 知识库被手动删除后，初始化会自动清理旧映射并重新创建；
- 已有知识库缺少模型绑定时自动补齐；
- 可以通过环境变量覆盖：
  - `DAM_WEKNORA_LLM_MODEL`
  - `DAM_WEKNORA_EMBEDDING_MODEL`

## 7. 维护体验

- 知识库顶部操作收敛为：
  ```text
  新增知识
  Agent 同步
  ```
- 知识详情可查看：
  - DAM 结构化内容；
  - WeKnora 摘要；
  - WeKnora 标签；
  - WeKnora 元数据；
  - 解析状态和错误。

## 8. 兼容性说明

- 旧知识分类会保留，并回填为一级分类；
- 旧的自由文本知识内容不会丢失，但建议重新补充类型、别名、字段映射等结构化字段；
- 旧的“指标口径”分类可以按新体系调整为“业务术语”或“指标解释”；
- 指标公式的权威定义仍以指标中心为准，知识库只保存解释、别名、来源和案例；
- 完整中英文分类路径如果超过 WeKnora 标签长度限制，后续需要使用“分类代码 + 分类名称”的短标签方案。

## 9. 数据库脚本

本次涉及的数据库脚本已放入包的 `db/` 目录，按部署规范执行。更新说明不展开数据库操作步骤。
