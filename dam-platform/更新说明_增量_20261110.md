# DAM 增量更新说明（2026-11-10）

本次为上一版 A/B 包之后的增量更新，仅说明功能与体验变化。

## 1. AI 工作台任务处理

- 任务队列支持「全部采纳 / 全部驳回」：
  - 不再需要逐条点击确认；
  - 按任务总待审数处理，不受当前明细分页影响；
  - 最多一次处理 5000 条明细。
- 运行中的任务支持「停止任务」：
  - 新增任务状态「已停止」；
  - 当前 AI 调用返回后不再继续下一批；
  - 停止后可删除任务；
  - 停止后的任务不允许继续审核。
- 任务统计增加已停止状态。

## 2. 运营看板性能优化

- 月度趋势由 24 次 COUNT 查询改为 2 次按月聚合查询。
- 平均质量评分改为数据库 AVG 聚合，不再加载全部资产到内存。
- 活跃用户改为数据库 COUNT(DISTINCT)。
- 工单状态、类型由多次 COUNT 改为分组聚合。
- 移除看板未使用、但会逐资产查询的资产价值分布计算。
- 修复无质量评分数据时看板空指针报错。

## 3. AI 注释任务体验

- 数据源「AI 补标注 / AI 全量标注」创建后台任务后立即返回；
- 不再在前端全屏轮询等待任务结束；
- 任务进度统一到「AI 工作台 → 任务队列」查看；
- 单表 AI 注释仍保持原有同步生成流程。

## 4. 知识库接入 WeKnora

- 新增 WeKnora 知识库客户端与迁移能力；
- 采用「一个 WeKnora 知识库 + 标签」：
  - DAM 知识分类映射为 WeKnora 标签；
  - DAM 知识条目迁移为 WeKnora manual 文档；
  - 写入 DAM 来源元数据，便于反向定位。
- 知识库页面增加：
  - Agent 知识库连接状态；
  - 迁移到 Agent 知识库；
  - 条目 Agent 同步状态；
  - 迁移结果统计。
- 新增外部检索接口：
  - 优先调用 WeKnora knowledge-search；
  - 外部失败或无结果时回退 DAM 本地知识库。
- 修复知识库页面 `KnowledgeBase` 组件未导入导致页面空白、不请求接口的问题。

## 5. 打包说明

- 不包含数据库操作说明；
- 原有历史更新说明保持不变。
